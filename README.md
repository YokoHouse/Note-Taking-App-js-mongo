# Note-Taking API

Този проект представлява просто REST API за създаване и управление на бележки. 
Използвани са Node.js, Express и MongoDB. Проектът е подходящ за учебни цели и показва основни операции като добавяне, извличане и търсене на данни.

## Функции

- Добавяне на нова бележка (title, tags)
- Преглед на всички бележки
- Търсене на бележки по текст (в заглавието)
- Филтриране по тагове
- Филтриране по дата

## Технологии

- Node.js
- Express.js
- MongoDB (с Mongoose)
- dotenv
